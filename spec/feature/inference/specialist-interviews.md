# 全対応職種の専門面接

指示: neco「技術者面接を仮想的に行いたい」「面接対応職種は全部」。
Actio: `366278aa-828b-47df-9149-4850d9b0b8b7`。

## 目的と範囲

現在の全対応職種（planner / programmer / designer / sound）に専門面接を提供する。
通常面接に加えて開始画面で専門面接と経験（学生・未経験 / 実務経験者）を選ぶ。
専門モードでは固定の現場面接官を使い、人事等のペルソナとの混在を防ぐ。
新しい音声処理・LLM経路・個人情報の保存先は作らない。

## 契約と責務

- `POST /api/v1/sessions` に任意の `specialist_interview: {role, level}` を追加。
  role は上記4職種、level は entry / experienced。target_role との不一致や
  interviewer_id の同時指定、不正な型・値はセッション確保前に400で拒否する。
- 検証済み設定のみ session metadata に保存。PG JSONB / SQLite TEXT の双方で
  再接続時・サマリー生成時に復元し再検証する。未指定は従来面接。
- interview-engine の職種定義・専門プロンプトが出題領域と講評観点を所有する。
  UI は選択、HTTP API は境界検証、SessionRuntime は既存の進行制御を担当する。
- 最初に得意分野を聞き、基礎・制作/設計課題・問題切り分け・検証と代替案を扱う。
  一度に一問とし、全領域の経験は必須にしない。未経験者には自主制作を認める。
- 既存6軸は維持する。専門講評は中間評価 comment/hints と最終サマリーの
  interviewer_note/growth_points/carry_over に、回答turnの根拠付きで記載する。
  未出題を能力不足と判定せず、ヒント利用・未確認事項を区別する。
- 実行していないコードや未閲覧の作品を検証済みと扱わない。採用合否は判定しない。
- 予約offer時に設定は保存されない（既存の開始APIと同じ）。予約枠の開始画面で再選択する。

## 受入条件

4職種×2経験を選択可能で、同じ専門設定が質問・中間評価・最終講評に届く。
質問プランの有効/無効どちらでも専門指示を含み、再接続後も保持される。
不正設定を拒否し、通常面接のプロンプトと評価形式は変えない。
ライブ面接・本番反映は別途許可と実行環境が必要。スタブ出力は専門能力の検証ではない。

## 技術者面談シミュレーション (シニア / 現場、2026-10-08 追加)

指示: neco「Trで技術者面談のシミュレーションを行う」「ESと企業が求める新卒像からシニアと現場とで聞きたい要点をリストアップする」「逆質問は知らないことも適当に答える」。

- `specialist_interview` に任意の `interviewer: field | senior` を追加。field = 現場エンジニア (peer-tech、1次技術面接)、senior = シニア / テックリード (lead-tech、2次技術面接)。
  未指定の旧セッションは経験レベルから従来どおり補う (entry → field、experienced → senior)。それ以外の値は400。
- 聞きたい要点: 面接官は ES (Memoria RAG 抜粋) と志望企業の求める新卒像 (company_newgrad_role_images → company_newgrad_images) から、
  シニアと現場それぞれが確かめたい要点を各6個以内で持つ。生成は `packages/llm/src/specialist-focus.ts`、取得と差し替えは `apps/server/src/ws/specialist-focus-loader.ts`。
  - 面接開始は待たせない。既定の要点 → 新卒像のテーマ入り → LLM が ES に当てた要点、の順に差し替える。LLM 不可・失敗時は既定の要点で続ける。
  - 要点は受験者の ES に由来するため DB へ保存しない (接続ごとに作り直す)。system prompt では選んだ面接官の要点を先に置き、もう一方は時間が余れば一つだけ扱う。
- 逆質問: 面接官は開発体制・チーム規模・技術・研修・キャリアなど資料に無いことも「わからない」で済ませず、もっともらしい内容で即答する。
  同じ面接内で矛盾させない。合否・内定・待遇の確約、実在人物や未公開タイトルの具体名は出さない。開始画面に「逆質問への答えは練習用の架空の内容」と示す。
- 受入条件: 4職種×2経験×2面接官を選べる。要点が質問プランの有効/無効どちらの system prompt にも載る。逆質問ルールが専門面接の指示に含まれる。通常面接のプロンプトは変えない。
