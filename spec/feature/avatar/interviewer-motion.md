# 面接官パネルのアバターと人間らしい動き

指示: neco「相手はなんかおじさん2-3人のアバターにしてください。アバターは別途Astraが作るのでOpusは人間の動きの再現を頑張って」
「Pictorのモデル描画使って」「テキストは面接感を出すためにも表示はせず、終わった後の反省で出す」(2026-10-08)。

## 構成と責務

| 層 | 担当 | 置き場所 |
|---|---|---|
| アバター (FBX) | Astra | 下記「アバターの契約」を満たす FBX。Tr リポには入れず、設定 JSON から参照する |
| 描画 | Pictor `fbx_viewer` の track 再生 (`SPEC-PC-FBX-TRACK-PLAYBACK`) | Pictor リポ。汎用機能で Tr を知らない |
| 動き | `packages/avatar` (純関数、描画非依存) | 時刻 → 論理名の姿勢。決定的 (同じ seed なら同じ動き) |
| 動画の組立 | `scripts/interview-video` | 音声合成・トラック出力・Pictor 実行・3 分割合成・振り返り |

画面はオンライン面接の 3 分割 (左: 現場エンジニア、中: テックリード = 進行役、右: プロデューサー = 聞き役)。
面接中は字幕・名札を出さない。発話の文字起こし・聞きたい要点・講評は面接後の「振り返り」で初めて出す。

## 人間らしい動き (packages/avatar)

| 振る舞い | 再現の仕方 |
|---|---|
| 口 | VOICEVOX の audio_query (合成に使った値そのもの) のモーラ長から口形を時刻に並べる。閉唇子音 (m/b/p) は口を閉じる。開きは 45ms・閉じは 70ms で前後の口形と重ねる (調音結合)。毎モーラ全開にせず開きを揺らす |
| まばたき | 平均 3.6 秒 (発話中 2.6 秒) を 0.35〜1.9 倍に散らす。13% は二度まばたき。閉 70ms・保持 30ms・開 120ms。大きな視線移動 (メモ・同席者) の半分にまばたきを伴う |
| 視線 | 目は 50ms のサッカード、頭は 80ms 遅れて 0.4 秒で角度の一部を追う。話し手は正面 (時々考えて視線を外してから戻る)。受験者の回答中は正面を見て、文節の切れ目で時々メモを取る (下を向く)。同席者が話すとそのタイルの方を見る |
| うなずき | 受験者の文節の切れ目で 42% の確率で相づち (25% は二度)、回答の終わりで受け止めのうなずき。話し手は文節の頭で小さく頭を振って強調。同席者の話にも時々同意 |
| 体 | 呼吸 (13〜16 回/分) で胸がゆっくり動く。話す 0.45 秒前に息を吸う。頭と胸の揺れは話している間に大きくなる |
| 表情 | 自分の問いかけの終わりで眉を上げる。あいさつ・礼で笑む。受験者の回答の受け止めで少し笑む。聞いている間は薄い笑みを保つ |

論理座標: `rx+` = うつむく、`ry+` = 画面右を向く、`rz+` = 首をかしげる (度)。リグ固有の軸と符号は設定 JSON で写す。

## アバターの契約 (Astra 向け)

- 形式: FBX (binary 7.4 以上)。1 体 1 ファイル、テクスチャは同じフォルダ。単位はメートル、Y が上、正面が +Z または -Z (設定 JSON のカメラで合わせる)。
- 人物: 40〜50 代の男性 3 人 (現場エンジニア / テックリード / プロデューサー)。胸から上が映る前提で、上半身と顔の作り込みを優先。座り姿勢で机は不要。
- 骨 (スキン): 少なくとも `Hips → Spine → Chest → Neck → Head` と `LeftEye` / `RightEye`。名前は任意 (設定 JSON で対応付け)。
- ブレンドシェイプ (必須): 口形 `A` `I` `U` `E` `O`、まばたき (両目 1 つ、または左右 2 つ)。
  推奨: 眉上げ (`BrowUp`)、笑み (`Smile`)。値 1.0 で最大の形。
- 名前は任意だが、`pictor_fbx_viewer <model> --list-channels` で骨名とシェイプ名が読めること。

## 設定 JSON (scripts/interview-video の --avatars)

```json
{
  "candidateVoice": { "designer": 8, "programmer": 12, "planner": 8, "sound": 8 },
  "avatars": [
    { "id": "field", "model": "path/to/field.fbx", "voice": 11, "camera": [0, 1.45, 0.9, 0, 1.4, 0], "clear": [0.2, 0.22, 0.25],
      "rig": {
        "bones": { "head": { "name": "Head" }, "neck": { "name": "Neck" }, "chest": { "name": "Chest" },
                   "eyeL": { "name": "LeftEye" }, "eyeR": { "name": "RightEye" } },
        "morphs": { "a": [{ "name": "A" }], "i": [{ "name": "I" }], "u": [{ "name": "U" }], "e": [{ "name": "E" }],
                    "o": [{ "name": "O" }], "blink": [{ "name": "Blink" }], "browUp": [{ "name": "BrowUp" }], "smile": [{ "name": "Smile" }] }
      } }
  ]
}
```

骨の `axes` で論理軸をリグの軸へ写す (例 `{"rx": {"axis": "rz", "sign": -1}, ...}`)。省略時は同じ軸・正の向き。

## 受入条件

- `packages/avatar` のテスト: まばたきの平均間隔 2〜5 秒・0.2 秒以内の重複なし、口は自分の発話中だけ動く、
  受験者の回答中にうなずく、メモ取りは回答中だけ、問いかけの終わりで眉が上がる、同じ seed で同じ動き、CSV が Pictor の形式。
- 動画: 面接中に文字が出ない。口の動きが音声とずれない。3 人がそれぞれ別のタイミングでまばたき・うなずきをする。最後に振り返りが付く。
